# Releases

[README](../README.md) · [Changelog](../CHANGELOG.md) · [Roadmap](ROADMAP.md)

**No public playable build is available.**

The internal diagnostic launcher and the standalone actor-test module are development tools, **not** a finished co-op launcher or a public game build.

Future public packages will specify:
- Matching client and server versions.
- Supported Fallout 4 and F4SE versions.
- Installation steps, known limitations, and tested game features.
- Appropriate third-party credits, license information, and file checks.

## Before a public build

- [ ] Two players can enter the same compatible game world.
- [ ] Remote player spawning and basic movement work in the real game.
- [ ] Disconnects and recovery are verified in complete sessions.
- [ ] Original single-player saves and settings are protected.
- [ ] Compatibility and installation have been tested.
- [ ] Required license and attribution materials are included.

The current development tests target a specific Fallout 4/F4SE setup; compatibility with other versions is **not** established by those results.

Example alpha or beta labels are not downloads.
